V16 比 V15 多了什麼？

Canonical mapping

每個 atom 都有固定 map number。

Bond order

single / double / aromatic 不再只是畫線。

Electron arrow

source 可選 atom/lone pair 或 bond；target 可選 atom/bond。

Valence guard

先檢查起始結構是否有 obvious over-valence。

V16 還沒有做完整 reaction graph rewriting。它會檢查箭頭「語法」與 starting valence，但不會自動宣稱箭頭後的 formal charge/bond-order 結果就是唯一正確產品。這是刻意保留的科學界線。
